# Vault Crypto for Obsidian

[English](README.md)

一款提供真实 AES-256-GCM 加密的 Obsidian 插件。不是 UI 遮罩——你的文件内容是真正加密的。

> ⚠️ **忘记密码 = 数据永久丢失。** 没有任何后门或恢复机制。

## 功能

- **文件加密**：右键任意 `.md` 文件 → 输入密码加密
- **文件夹加密**：右键文件夹 → 加密文件夹内所有 `.md` 文件
- **三态模型**：加密(锁定) → 临时查看(切走自动重加密) → 完全解密(永久明文)
- **锁定遮罩**：加密文件打开后显示锁定界面，而非乱码
- **自动锁定**：无操作 N 分钟后自动重加密（默认 1 分钟）
- **加密前确认**：防止误操作加密（默认开启）
- **导出解密工具**：导出独立 HTML 文件——接收方在浏览器打开，输入密码即可解密
- **同步友好**：原地加密（文件保持 `.md`）——兼容 Syncthing、iCloud、Dropbox
- **零依赖**：纯 Web Crypto API（`crypto.subtle`），macOS 和 iOS 均可用

## 加密参数

| 参数 | 值 |
|------|-----|
| 算法 | AES-256-GCM |
| 密钥派生 | PBKDF2-SHA512，1,000,000 次迭代 |
| Salt | 128-bit 随机（每次加密唯一） |
| IV | 96-bit 随机（每次加密唯一） |
| 文件标记 | `-----VAULT-CRYPTO-----` 头部 |

加密后文件格式：
```
-----VAULT-CRYPTO-----
<base64(JSON{salt, iv, ciphertext, iter})>
```

`iter` 字段记录加密时使用的 PBKDF2 迭代次数，确保默认值变更时向后兼容。

文件扩展名保持 `.md`——只有内容被替换为密文。同步工具看到的是一个内容不可读的普通 `.md` 文件。

## 安装

1. 前往 [最新 Release](https://github.com/jsfbest/vault-crypto/releases/latest)
2. 下载 3 个文件：`main.js`、`manifest.json`、`styles.css`
3. 在你的 Obsidian vault 中创建目录：`.obsidian/plugins/vault-crypto/`
4. 将下载的 3 个文件复制到该目录
5. 重启 Obsidian → 设置 → 社区插件 → 启用 **Vault Crypto**

## 使用

### 加密文件

1. 在文件列表中右键 `.md` 文件
2. 点击 **加密文件**
3. 如开启了"加密前确认"（默认开启），确认操作
4. 输入密码两次（确认密码必须一致，最少 4 位）

### 查看加密文件（临时解密）

1. 打开加密文件 → 看到锁定遮罩
2. 右键编辑区 → 点击 **查看加密文件**
3. 输入密码一次 → 明文临时显示
4. 切走文件或等待超时 → **自动重加密**

### 完全解密文件

1. 右键加密文件 → 点击 **完全解密文件**
2. 输入密码一次 → 文件永久恢复为明文

### 导出解密工具

1. 右键加密文件 → 点击 **导出解密工具**
2. 桌面端：弹出系统保存对话框，选择保存位置
3. 移动端：HTML 文件保存到原 .md 文件同目录
4. 将导出的 HTML 文件发给对方，对方在浏览器中打开输入密码即可解密

通用解密页面（粘贴密文模式）也可从仓库 `tools/decrypt.html` 下载使用。

### 命令面板

`Cmd/Ctrl + P` 搜索：

| 命令 | 描述 |
|------|------|
| 加密当前文件 | 用密码加密当前文件 |
| 查看加密当前文件 | 临时查看加密文件（切走自动重加密） |
| 完全解密当前文件 | 永久解密当前文件 |
| 加密当前文件所在文件夹 | 加密当前文件夹所有 .md 文件 |
| 完全解密当前文件所在文件夹 | 永久解密当前文件夹所有加密 .md 文件 |
| 导出解密工具 | 为当前加密文件导出独立解密 HTML |

## 设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 自动锁定时间 | 1 分钟 | 临时查看后无操作 N 分钟自动重加密，0 = 关闭 |
| 加密前确认 | 开启 | 加密操作前弹出确认框 |

## 重要提醒

- **忘记密码 = 数据永久丢失**，没有任何恢复机制
- 建议定期备份 vault
- 附件（图片、PDF）当前**不会被加密**
- 同一加密文件不要在多台设备同时操作，避免同步冲突
- "查看加密文件"是临时操作（切走自动重加密）；"完全解密文件"是永久操作

## 开发

```bash
git clone https://github.com/jsfbest/vault-crypto.git
cd vault-crypto
npm install
npm run dev    # 开发模式
npm run build  # 生产构建
```
