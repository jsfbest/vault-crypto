# 需求文档

## 用户需求

用户想要在 Obsidian 中给特定 .md 文件或整个文件夹的 .md 加密，每次查看需输入密码。

## 使用场景

1. **本地隐私保护**：防止别人拿到电脑时看到敏感笔记（日记、密码、财务等）
2. **多设备同步安全**：笔记通过 Syncthing 同步，云端看到的也是密文
3. 两者都要

## 功能需求

### P0 — MVP（已实现）

| 功能 | 描述 | 状态 |
|------|------|------|
| 单文件加密 | 右键 .md → 确认 → 选密码 → 文件内容替换为密文 | ✅ |
| 临时查看加密文件 | 右键加密文件 → 查看加密文件 → 输密码 → 临时显示明文，切走自动重加密 | ✅ |
| 完全解密文件 | 右键加密文件 → 完全解密文件 → 输密码 → 永久写回明文 | ✅ |
| 文件夹加密 | 右键文件夹 → 选密码 → 文件夹下所有 .md 加密（跳过已加密的） | ✅ |
| 文件夹解密 | 右键加密文件夹 → 输密码 → 文件夹下所有加密 .md 完全解密 | ✅ |
| 锁定遮罩 | 加密文件打开后显示"此文件已加密"遮罩，提示右键操作 | ✅ |
| 加密前确认 | 弹出确认对话框，防止误加密 | ✅ |
| 自动锁定 | 无操作 N 分钟后自动重加密临时查看的文件（默认 1 分钟） | ✅ |

## UX 设计

### 加密流程

1. 用户右键文件/文件夹 → 点击"加密文件"或"加密文件夹"
2. 如果开启了"加密前确认"（默认开启），弹出确认框
3. 弹出密码输入框（加密模式：需输入两次确认）
4. 输入密码 → 文件内容原地替换为密文（.md 扩展名不变）

### 查看加密文件（临时解密）

1. 用户打开加密文件 → 看到锁定遮罩（"此文件已加密"）
2. 右键编辑区或文件标签页 → "查看加密文件"
3. 输入密码一次 → 明文内容临时显示
4. 切走文件或超时 → 自动重加密

### 完全解密流程

1. 右键加密文件 → "完全解密文件"
2. 输入密码一次 → 文件永久写回明文

### 关键设计决策

- **不改扩展名**：加密后仍是 `.md`，内容替换为密文 → 同步工具正常工作
- **锁定遮罩无按钮**：用户通过右键菜单或命令面板操作，避免 Obsidian 内部 API 限制
- **三态模型**：加密是稳态，明文是临时态 → 切走自动重加密，默认安全
- **Web Crypto API**：零依赖，macOS + iOS 都能用
- **单设备操作约定**：不加写后验证逻辑，靠用户约定同一时间只在一台设备操作加密文件
- **密码可解密**：密码 + 加密文件 = 任何人可解密，不依赖 Obsidian 插件（但需要解密工具）

## 同步方案

用户使用 **Syncthing** 同步文件。

Syncthing 是文件系统级同步，不关心文件内容格式。我们的原地加密方案（不改 `.md` 扩展名）与 Syncthing 天然兼容：
- 明文 → 密文 = 正常的文件内容变更，Syncthing 正常同步
- 不存在 Meld Encrypt 的 `.mdenc` 不同步问题

**风险约定**：同一时间只在一台设备上操作加密文件，避免 Syncthing 冲突。
