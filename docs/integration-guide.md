# 使用指南

## 安装

### 方式一：手动安装（当前唯一方式）

1. 构建：`npm run build`
2. 在 Obsidian vault 中创建目录：`<vault>/.obsidian/plugins/vault-crypto/`
3. 复制以下文件到该目录：
   - `main.js`
   - `manifest.json`
   - `styles.css`
4. 重启 Obsidian
5. 设置 → 社区插件 → 启用 "Vault Crypto"

### 方式二：开发模式

1. `npm run dev` 启动 esbuild watch
2. 把 `main.js` + `manifest.json` + `styles.css` 软链接到 vault 的插件目录
3. 编辑源码后，Obsidian 自动热加载

## 使用

### 加密单个文件

1. 在文件列表中**右键** .md 文件
2. 点击 **加密文件**
3. 如开启了"加密前确认"（默认开启），确认操作
4. 输入密码两次（确认密码必须一致，最少 4 位）
5. 文件内容替换为密文

### 查看加密文件（临时解密）

1. 点击已加密的 .md 文件 → 看到锁定遮罩（"此文件已加密"）
2. **右键**编辑区或文件标签页 → 点击 **查看加密文件**
3. 输入密码一次 → 明文临时显示
4. 切走文件或超时（默认 1 分钟）→ **自动重加密**

> 提示：临时查看期间可以编辑文件，编辑的内容会在重加密时一并保存为密文。

### 完全解密文件

1. **右键**加密文件的文件标签页 → 点击 **完全解密文件**
2. 输入密码一次 → 文件**永久**写回明文

### 加密文件夹

1. 在文件列表中**右键**文件夹
2. 点击 **加密文件夹**
3. 如开启了"加密前确认"，确认操作
4. 输入密码两次
5. 文件夹下所有 .md 文件逐一加密
6. 加密完成后提示：成功 N 个，跳过 N 个（已加密），失败 N 个

### 完全解密文件夹

1. 右键已加密文件夹
2. 点击 **完全解密文件夹**
3. 输入密码一次
4. 文件夹下所有加密 .md 逐一完全解密

### 导出加密HTML

1. 右键加密文件 → 点击 **导出加密HTML**
2. 桌面端：弹出系统保存对话框，选择保存位置和文件名
3. 移动端：HTML 文件保存到原 .md 文件同目录（文件名如 `diary-decrypt.html`）
4. 将导出的 HTML 文件发给对方，对方在浏览器中打开输入密码即可解密
5. 文件已存在会自动覆盖

> 通用解密页面（粘贴模式）也可从仓库 `tools/decrypt.html` 下载使用。

### 命令面板

`Cmd/Ctrl + P` 搜索：

| 命令 | 描述 |
|------|------|
| 加密当前文件 | 加密当前打开的文件 |
| 查看加密当前文件 | 临时查看加密文件（切走自动重加密） |
| 完全解密当前文件 | 永久解密当前文件 |
| 加密当前文件所在文件夹 | 加密当前文件所在文件夹的所有 .md |
| 完全解密当前文件所在文件夹 | 永久解密当前文件所在文件夹的所有加密 .md |
| 导出加密HTML | 导出独立解密 HTML（桌面端系统对话框，移动端 vault 内） |

## 设置

设置 → Vault Crypto：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 自动锁定时间 | 1 分钟 | 临时查看后无操作 N 分钟自动重加密，0 = 关闭 |
| 加密前确认 | 开启 | 加密操作前弹出确认框 |

## ⚠️ 重要提醒

- **忘记密码 = 数据永久丢失**，没有任何恢复机制
- 建议定期备份 vault
- 加密后文件仍是 `.md`，内容不可读但文件存在 → Syncthing 正常同步
- 附件（图片、PDF）当前**不会被加密**，后续版本支持
- 同一加密文件不要在多台设备同时操作，避免 Syncthing 冲突
- "查看加密文件"是临时操作，切走文件会自动重加密；"完全解密文件"是永久操作
